# Environment Report

## Setup
- **OS**: macOS (ARM64)
- **Python**: Python 3.9
- **Java**: OpenJDK 17
- **Spark**: PySpark 3.5.1 (or latest)
- **Dependencies**: pandas, numpy, yfinance, matplotlib, streamlit, pytest

## Instructions
To setup the environment:
1. `python3 -m venv .venv`
2. `source .venv/bin/activate`
3. `pip install -r requirements.txt`
4. Make sure Java is installed and `JAVA_HOME` is set.
